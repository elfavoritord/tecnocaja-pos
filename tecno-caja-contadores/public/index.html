✉ Correo para enviar facturas

Con esto, cada factura se le envía a tu cliente desde tu propio Gmail, con el PDF adjunto. Se configura una sola vez y toma unos 3 minutos.

📋 Cómo conseguir tu contraseña de aplicación (paso a paso)
  1. Enciende la Verificación en 2 pasos de tu cuenta de Google.
    Presiona el botón, inicia sesión con tu Gmail y sigue las instrucciones (te pedirá tu número de teléfono). Si ya la tienes activada, salta al paso 2.
  2. Crea la contraseña de aplicación.
    Se abre una página. Donde dice "Nombre de la app" escribe Tecno Caja y presiona Crear.
  3. Copia el código que te da Google.
    Son 16 letras en 4 grupos, por ejemplo abcd efgh ijkl mnop. Cópialas tal cual — no importa si llevan espacios.
  4. Llena el formulario de abajo (tu Gmail + el código + el nombre de tu firma) y presiona Guardar y probar. Si todo está bien, verás "✅ Conectado".
⚠️ ¿No te aparece la opción "Contraseñas de aplicaciones"? Es porque todavía no activaste la Verificación en 2 pasos (paso 1). Hazlo primero y vuelve a intentar.
🤖 Asistente virtual (IA)

El asistente usa Google Gemini. Necesitas una API key gratuita de Google AI Studio. Se configura una sola vez y solo tú la usas (tu propio consumo).

📋 Cómo obtener tu API key (gratis, 1 minuto)
  1. Abre Google AI Studio e inicia sesión con tu cuenta de Google.
  2. Presiona "Crear clave de API" / "Create API key".
  3. Copia la clave (empieza con AIza…) y pégala abajo.

📁 Generar 606/607/608 desde archivo del negocio

Pide a tu cliente que exporte el archivo fiscal desde Tecno Caja POS (Reportes → Fiscal DGII → "📤 Exportar para el Contador") y súbelo aquí para generar los formatos de envío 606, 607 y 608.

⚠️ Verifica el formato contra la Guía de Envío vigente de la DGII antes de presentar. Algunas columnas (retenciones, ISC, tipo de bienes/servicios) se completan en 0 porque el POS aún no las captura por transacción — revísalas con el cliente antes de enviar.
